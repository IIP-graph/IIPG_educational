Software available

A collection of advanced software tools have been developed for Process Systems Engineering, optimization, and decision support, all built upon the rigorous theoretical foundations of the P-graph framework.
These platforms transform complex process design challenges into structured, solvable problems, enabling researchers, engineers, and industry professionals to discover optimal solutions, evaluate alternatives, and accelerate innovation.
This page provides an overview of the available software, highlighting their capabilities, applications, and access information.

P-Graph Studio

Main use: Industry, research, and education
Extensively applied in both industrial and research contexts, including chemical engineering, industrial process design, supply chains design and systems optimization.
Graphical interface
The software has a graphical interface for modeling, which facilitates its use for education purposes
Integrated algorithms
Integrated P-graph algorithms enable ennumerating feasible structures and identifying n-best solutions for synthesis and optimization of complex processing systems.
Multiperiod problems
Easy formuation of problems with multiple periods (muti-period formulation) including storage and waste treatment.
P-graph for scheduling problems
Implementation of time-constrained process network synthesis model for solving scheduling problems using P-graph.
P-Graph Studio is a specialized software environment for process network synthesis (PNS), built on the graph-theoretical foundations of the P-graph framework.

Status: Available
License: Open Source
Platform: Windows

Python library: ProcessGraph

ProcessGraph is a Python library developed to serve as an interface between P-Graph Studio solver and Python programming ecosystem.

Status: Available and under continuous development
License: Open Source
Platform: Windows

GitHub repository
Teng, S.Y., Orosz, Á., How, B.S., Pimentel, J., Friedler, F., Jansen, J.J., 2022. Framework to embed machine learning algorithms in P-graph: Communication from the chemical process perspectives. Chemical Engineering Research and Design 188, 265–270
Main use
Mainly deployed in education and research contexts in which the graphical input of is not required.
Systematic problem formulation and higher flexibility
Python code can be use to systematically formulate the synthesis problems and allows larger flexibility solution and analysis by enabling the use of modified solvers and automation of examinations.
Integration with Python libraries
The results of the examination can be further exploited by using data analysis and plotting libraries. It also provides an interface with machine-learning and AI methods

P-graph Insight

Main use
Primary tool for education and learning the principles of the P-graph Framework.
Demonstration of the framework's main algorithms
The software contains the basic (i.e., non-optimized) implementations of the framework's algorithms, and is designed to give insight on their operation.
Demonstration tool for the main concepts and algorithms of the P-graph framework.

PHENS

Software specialized for P-graph in Heat Exchanger Network Synthesis (P-HENS). The examination can be carried out considering structural constraints of decision-makers such as:
  • Specification of practical considerations
  • Number of HE per stream
  • Maximum splitting
  • Max deviation from minimum utility consumption

Status: Available and under continuous development

License: Open Source
Platform: Windows

Email: Dr. Ákos Orosz (orosz@dcs.uni-pannon.hu)
Orosz, Á., How, B.S., Friedler, F., 2022. Multiple-solution heat exchanger network synthesis using P-HENS solver. Journal of the Taiwan Institute of Chemical Engineers 130, 103859
Main use
Mainly deployed in research of problems involving heat integration. Cost examination can be performed via integration with non-linear solvers
Capabilities
Enumeration of HEN for energy recovery satisfying minimum utility consumption that enables the evaluation of various practical considerations related to the network's structure.

Reaction Pathway Identification

Main use
Software for research and education in reaction pathways identification.
Reaction pathway identification
The software utilizes algorithms RPIMSG, RPISSG, RPIPBT, and RPIPBTD for the identification of plausible reaction mechanisms.
Software for enumeration of potentially feasible pathways for chemical and biological reactions.

Status: Available and under continuous development
